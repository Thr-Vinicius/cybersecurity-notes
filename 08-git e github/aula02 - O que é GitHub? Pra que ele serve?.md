## GitHub

O GitHub é uma plataforma online utilizada para hospedar repositórios Git,
compartilhar projetos e colaborar com outras pessoas.

### Principais características

- Criação de repositórios públicos e privados ilimitados.
- Hospedagem de projetos e códigos-fonte.
- Recursos semelhantes aos de uma rede social.
- Integração com o GitHub Pages.
- Colaboração por meio de:
  - Issues;
  - Pull requests;
  - Discussions;
  - Projects;
  - Organizations.

### Plataformas alternativas

- GitLab;
- Bitbucket;
- Gitea.

## Possibilidades de uso

- Armazenar projetos públicos e privados.
- Manter um histórico de projetos pessoais.
- Divulgar trabalhos e criar um portfólio.
- Colaborar com outros desenvolvedores.
- Conhecer e acompanhar projetos de outras pessoas.
- Participar da comunidade de desenvolvimento.
